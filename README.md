# B16 Immersive Frontend

Skill para planejar, desenhar e revisar landing pages e sites com composição visual marcante, animação e, quando fizer sentido, 3D. Inclui guias de briefing, escolha de tecnologias e verificação.

Baixe o ZIP na seção Releases e extraia a pasta inteira `b16-immersive-frontend`. Para usar no Codex, coloque a pasta em `~/.agents/skills/`. Para usar no Claude Code, coloque em `~/.claude/skills/`. Mantenha `SKILL.md` e as pastas de referência juntos.
